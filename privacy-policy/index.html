Privacy Policy: ArtScapesBySnow Pin Scheduler

Last updated: November 5, 2026

ArtScapesBySnow Pin Scheduler ("the app") is a private tool used only by the owner of the ArtScapesBySnow shop to publish pins about the shop's own products to the owner's own Pinterest account. It is not offered to the public, and no one else can sign in to it.

What the app accesses

  • The owner's Pinterest account, through the official Pinterest API, with only the permissions needed to read the owner's own boards, create pins on them, and read basic performance statistics (such as impressions, saves and clicks) for the owner's own pins.
  • Images and text the owner created about the shop's own products. These are stored on the owner's own computer.

What the app does not do

  • It does not collect, store or process personal data about other Pinterest users, shop customers or anyone else.
  • It does not read other users' pins, profiles or boards, and it does not scrape Pinterest.
  • It does not sell, share or transfer any data to third parties.
  • It does not use Pinterest data for advertising, analytics resale or training AI models.

Storage and security

Access tokens are stored only on the owner's computer in a private file that is never published or shared. Tokens can be revoked at any time from the owner's Pinterest account settings.
